OOP Rule — Routes are THINসবচেয়ে গুরুত্বপূর্ণ নিয়ম
✓ Route করবে:
Request validate (Zod) → Service method call → Response send। ব্যস।
✗ Route করবে না:
Prisma query সরাসরি, business logic, file upload handle, notification trigger — এগুলো সব Service এ।
